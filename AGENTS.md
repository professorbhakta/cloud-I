# AGENTS.md

## Cursor Cloud specific instructions

This repository is **documentation-only**. It contains plain-text cloud-computing
study notes and a one-line `README.md`. There is:

- No application source code, and nothing to build or serve.
- No package manager, lockfile, dependencies, database, or external service.
- No test suite, linter config, or CI build step.

### Working in this repo

- The "content" lives in `cloud-computing-notes/*.txt` (plain text) and `README.md`.
- To "run" the project you simply open/read the `.txt` files; there is no dev server.
- No dependency install is required — the environment update script is intentionally a no-op.
- If you add tooling later (e.g. a markdown renderer or linter), update this section
  and the update script accordingly.
